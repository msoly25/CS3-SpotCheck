# CS3-SpotCheck
# Motivation and Context
Accurately identifying species is important for understanding biodiversity and changes in local ecosystems. However, visually similar species can be difficult to distinguish, particularly for people without specialized identification experience.

This project explores how machine learning and image classification can support species identification. Using photographs of two lady beetle species, the project develops a model that learns visual patterns from labeled images and evaluates how well it classifies images it has not seen during training.

The project also examines the limitations of automated classification. A model's predictions are not always correct, and its performance on a limited image dataset does not necessarily demonstrate how well it would perform across different environments, backgrounds, lighting conditions, or image qualities.
